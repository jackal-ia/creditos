1. Resumen Ejecutivo

1.1 Alcance del cambio

El presente informe documenta la creación e implementación de la API de Reportes Dinámicos v1.0, un módulo backend que permite generar reportes personalizados de las tiendas (Caracas, Maracay, Maracaibo) con filtros avanzados, resumen automático y exportación a múltiples formatos (JSON, CSV/Excel, PDF).

La API no modifica ningún componente existente del sistema. Se implementa como un endpoint adicional que consume los mismos datos de PostgreSQL pero ofrece capacidades que los filtros actuales del frontend no pueden proporcionar.

3. Arquitectura de la API

3.1 Diagrama de flujo

Flujo de datos:
1. Frontend envía POST a /api/reportes/v1/generar con body JSON (tienda, tipo, filtros, formato)
2. Auth middleware valida JWT y extrae rol/tienda del usuario
3. Query Builder construye SQL dinámico con parámetros seguros ($1, $2)
4. PostgreSQL ejecuta SELECT y devuelve filas
5. Formateador calcula resumen (totales, promedios, %)
6. Exportador convierte a JSON, CSV o PDF según el parámetro formato
7. Respuesta vuelve al frontend con datos + resumen

3.2 Componentes del sistema

// ============================================================
// API DE REPORTES DINAMICOS v1.0 — Sistema de Creditos IPSFA
// ============================================================
// Fecha: 2026-07-27
// Descripcion: Endpoint unificado para generar reportes de tiendas
//              con filtros avanzados, resumen automatico y exportacion.
// ============================================================

const express = require('express');
const pool = require('../config/database');
const { verificarToken } = require('../middleware/auth');

const router = express.Router();

// Mapa de tiendas a tablas de PostgreSQL
const TABLAS_TIENDA = {
    caracas: 'tienda_caracas',
    maracay: 'tienda_maracay',
    maracaibo: 'tienda_maracaibo'
};

// Tipos de reporte soportados
const TIPOS_REPORTE = ['cartera', 'cobranza', 'deudores', 'cuotas'];

// Formatos de salida soportados
const FORMATOS_SALIDA = ['json', 'excel', 'pdf'];

// ============================================================
// ENDPOINT PRINCIPAL: POST /api/reportes/v1/generar
// ============================================================
router.post('/generar', verificarToken, async (req, res) => {
    try {
        const {
            tienda,
            tipo = 'cartera',
            formato = 'json',
            filtros = {},
            ordenarPor = 'id',
            orden = 'asc',
            pagina = 1,
            porPagina = 100
        } = req.body;

        // ---------- VALIDACIONES ----------
        if (!tienda) {
            return res.status(400).json({
                error: 'El campo "tienda" es obligatorio',
                tiendas_disponibles: Object.keys(TABLAS_TIENDA)
            });
        }

        const tabla = TABLAS_TIENDA[tienda];
        if (!tabla) {
            return res.status(400).json({
                error: 'Tienda no valida',
                tiendas_disponibles: Object.keys(TABLAS_TIENDA)
            });
        }

        if (!TIPOS_REPORTE.includes(tipo)) {
            return res.status(400).json({
                error: 'Tipo de reporte no valido',
                tipos_disponibles: TIPOS_REPORTE
            });
        }

        if (!FORMATOS_SALIDA.includes(formato)) {
            return res.status(400).json({
                error: 'Formato no valido',
                formatos_disponibles: FORMATOS_SALIDA
            });
        }

        // Seguridad: operador solo ve su tienda
        if (req.usuario.rol === 'operador' && req.usuario.tienda && req.usuario.tienda !== tienda) {
            return res.status(403).json({ error: 'No tiene acceso a esta tienda' });
        }

        // ---------- CONSTRUIR QUERY ----------
        const { query, params, countQuery, countParams } = construirQuery(
            tipo, tabla, filtros, ordenarPor, orden
        );

        // Ejecutar query principal
        const result = await pool.query(query, params);

        // Ejecutar query de conteo (para paginacion)
        const countResult = await pool.query(countQuery, countParams);
        const totalRegistros = parseInt(countResult.rows[0].count);

        // ---------- FORMATEAR DATOS ----------
        const datos = formatearReporte(tipo, result.rows);
        const resumen = calcularResumen(tipo, datos);

        // ---------- RESPONDER SEGUN FORMATO ----------
        if (formato === 'excel') {
            return exportarCSV(res, datos, `reporte_${tipo}_${tienda}_${new Date().toISOString().split('T')[0]}`);
        }

        if (formato === 'pdf') {
            return exportarPDF(res, datos, resumen, `reporte_${tipo}_${tienda}`);
        }

        // Default: JSON
        res.json({
            exito: true,
            tipo,
            tienda,
            totalRegistros,
            pagina,
            porPagina,
            totalPaginas: Math.ceil(totalRegistros / porPagina),
            resumen,
            datos
        });

    } catch (error) {
        console.error('[API Reportes] Error:', error);
        res.status(500).json({
            error: 'Error al generar reporte',
            details: error.message
        });
    }
});

// ============================================================
// QUERY BUILDER DINAMICO
// ============================================================
function construirQuery(tipo, tabla, filtros, ordenarPor, orden) {
    const where = ['1=1'];
    const params = [];
    let idx = 1;

    // Filtro: fecha desde
    if (filtros.fechaDesde) {
        where.push(`fecha_factura >= $${idx++}`);
        params.push(filtros.fechaDesde);
    }

    // Filtro: fecha hasta
    if (filtros.fechaHasta) {
        where.push(`fecha_factura <= $${idx++}`);
        params.push(filtros.fechaHasta);
    }

    // Filtro: estado
    if (filtros.estado && filtros.estado !== 'todos') {
        switch (filtros.estado) {
            case 'aldia':
                where.push('deuda <= 0');
                break;
            case 'deudor':
                where.push('deuda > 0');
                break;
            case 'incompleto':
                where.push('monto_depositados > 0 AND deuda > 0');
                break;
            case 'sinpago':
                where.push('monto_depositados = 0 OR monto_depositados IS NULL');
                break;
        }
    }

    // Filtro: monto minimo
    if (filtros.minDeuda !== undefined && filtros.minDeuda !== null) {
        where.push(`deuda >= $${idx++}`);
        params.push(parseFloat(filtros.minDeuda));
    }

    // Filtro: monto maximo
    if (filtros.maxDeuda !== undefined && filtros.maxDeuda !== null) {
        where.push(`deuda <= $${idx++}`);
        params.push(parseFloat(filtros.maxDeuda));
    }

    // Filtro: busqueda por nombre o cedula
    if (filtros.busqueda) {
        where.push(`(nombre_apellido ILIKE $${idx} OR cedula ILIKE $${idx})`);
        params.push(`%${filtros.busqueda}%`);
        idx++;
    }

    // Filtro: tipo de venta
    if (filtros.tipoVenta && filtros.tipoVenta !== 'todos') {
        where.push(`tipo_venta = $${idx++}`);
        params.push(filtros.tipoVenta);
    }

    // Columnas segun tipo de reporte
    let select;
    switch (tipo) {
        case 'cartera':
            select = `SELECT id, nro_factura, nombre_apellido, cedula, telefono,
                      monto_factura, monto_depositados, deuda, fecha_factura,
                      tipo_venta, tasa_bcv, cuota_inicial, deuda_usd, cuotas`;
            break;
        case 'cobranza':
            select = `SELECT id, nro_factura, nombre_apellido, cedula,
                      cuota_1, ref_cuota_1, fecha_cuota_1,
                      cuota_2, ref_cuota_2, fecha_cuota_2,
                      cuota_3, ref_cuota_3, fecha_cuota_3,
                      cuota_4, ref_cuota_4, fecha_cuota_4,
                      monto_depositados, deuda, fecha_factura`;
            break;
        case 'deudores':
            select = `SELECT id, nro_factura, nombre_apellido, cedula,
                      monto_factura, monto_depositados, deuda, fecha_factura,
                      tipo_venta, cuotas`;
            where.push('deuda > 0');
            break;
        case 'cuotas':
            select = `SELECT id, nro_factura, nombre_apellido,
                      cuota_1, ref_cuota_1, fecha_cuota_1, tasa_cuota_1, dolar_depositado_cuota_1,
                      cuota_2, ref_cuota_2, fecha_cuota_2, tasa_cuota_2, dolar_depositado_cuota_2,
                      cuota_3, ref_cuota_3, fecha_cuota_3, tasa_cuota_3, dolar_depositado_cuota_3,
                      cuota_4, ref_cuota_4, fecha_cuota_4, tasa_cuota_4, dolar_depositado_cuota_4`;
            break;
        default:
            select = 'SELECT *';
    }

    // Ordenamiento seguro (whitelist de columnas)
    const columnasPermitidas = {
        id: 'id', nombre: 'nombre_apellido', fecha: 'fecha_factura',
        deuda: 'deuda', monto: 'monto_factura', factura: 'nro_factura'
    };
    const colOrden = columnasPermitidas[ordenarPor] || 'id';
    const dirOrden = orden === 'desc' ? 'DESC' : 'ASC';

    const whereClause = where.join(' AND ');

    const query = `${select} FROM ${tabla} WHERE ${whereClause} ORDER BY ${colOrden} ${dirOrden} LIMIT 1000`;
    const countQuery = `SELECT COUNT(*) FROM ${tabla} WHERE ${whereClause}`;

    return { query, params, countQuery, countParams: params };
}

// FORMATEADOR DE DATOS
// ============================================================
function formatearReporte(tipo, rows) {
    switch (tipo) {
        case 'cartera':
            return rows.map(r => ({
                id: r.id,
                factura: r.nro_factura,
                cliente: r.nombre_apellido,
                cedula: r.cedula,
                telefono: r.telefono,
                montoBs: parseFloat(r.monto_factura) || 0,
                depositadoBs: parseFloat(r.monto_depositados) || 0,
                deudaBs: parseFloat(r.deuda) || 0,
                estado: (parseFloat(r.deuda) || 0) <= 0 ? 'Al dia' : 'Deudor',
                tipoVenta: r.tipo_venta || 'credito',
                tasaBCV: parseFloat(r.tasa_bcv) || 0,
                cuotaInicialUSD: parseFloat(r.cuota_inicial) || 0,
                deudaUSD: parseFloat(r.deuda_usd) || 0,
                numCuotas: parseInt(r.cuotas) || 0,
                fecha: r.fecha_factura
            }));

        case 'cobranza':
            return rows.map(r => {
                const cuotasPagadas = [1,2,3,4].filter(i => {
                    const monto = parseFloat(r[`cuota_${i}`]);
                    return monto > 0;
                }).length;
                return {
                    id: r.id,
                    factura: r.nro_factura,
                    cliente: r.nombre_apellido,
                    cedula: r.cedula,
                    cuotasPagadas,
                    totalDepositado: parseFloat(r.monto_depositados) || 0,
                    deudaRestante: parseFloat(r.deuda) || 0,
                    fecha: r.fecha_factura
                };
            });

        case 'deudores':
            return rows.map(r => ({
                id: r.id,
                factura: r.nro_factura,
                cliente: r.nombre_apellido,
                cedula: r.cedula,
                montoTotal: parseFloat(r.monto_factura) || 0,
                depositado: parseFloat(r.monto_depositados) || 0,
                deuda: parseFloat(r.deuda) || 0,
                diasSinPago: calcularDiasMora(r.fecha_factura),
                tipoVenta: r.tipo_venta || 'credito',
                fecha: r.fecha_factura
            }));

        case 'cuotas':
            return rows.map(r => {
                const cuotas = [];
                for (let i = 1; i <= 4; i++) {
                    const monto = parseFloat(r[`cuota_${i}`]) || 0;
                    if (monto > 0) {
                        cuotas.push({
                            numero: i,
                            montoBs: monto,
                            referencia: r[`ref_cuota_${i}`] || null,
                            fecha: r[`fecha_cuota_${i}`] || null,
                            tasaBCV: parseFloat(r[`tasa_cuota_${i}`]) || null,
                            montoUSD: parseFloat(r[`dolar_depositado_cuota_${i}`]) || null
                        });
                    }
                }
                return {
                    id: r.id,
                    factura: r.nro_factura,
                    cliente: r.nombre_apellido,
                    cuotas
                };
            });

        default:
            return rows;
    }
}

// ============================================================
// CALCULADOR DE RESUMEN
// ============================================================
function calcularResumen(tipo, datos) {
    if (datos.length === 0) {
        return { totalRegistros: 0, totalFacturado: 0, totalDepositado: 0, totalDeuda: 0 };
    }

    if (tipo === 'cartera' || tipo === 'deudores') {
        const totalFacturado = datos.reduce((s, d) => s + (d.montoBs || d.montoTotal || 0), 0);
        const totalDepositado = datos.reduce((s, d) => s + (d.depositadoBs || d.depositado || 0), 0);
        const totalDeuda = datos.reduce((s, d) => s + (d.deudaBs || d.deuda || 0), 0);
        const clientesAlDia = datos.filter(d => (d.deudaBs || d.deuda || 0) <= 0).length;
        const clientesDeudores = datos.filter(d => (d.deudaBs || d.deuda || 0) > 0).length;

        return {
            totalRegistros: datos.length,
            totalFacturado: parseFloat(totalFacturado.toFixed(2)),
            totalDepositado: parseFloat(totalDepositado.toFixed(2)),
            totalDeuda: parseFloat(totalDeuda.toFixed(2)),
            clientesAlDia,
            clientesDeudores,
            porcentajeRecuperacion: totalFacturado > 0
                ? parseFloat(((totalDepositado / totalFacturado) * 100).toFixed(2))
                : 0
        };
    }

    if (tipo === 'cobranza') {
        const totalCuotasPagadas = datos.reduce((s, d) => s + (d.cuotasPagadas || 0), 0);
        const totalDepositado = datos.reduce((s, d) => s + (d.totalDepositado || 0), 0);
        return {
            totalRegistros: datos.length,
            totalCuotasPagadas,
            totalDepositado: parseFloat(totalDepositado.toFixed(2))
        };
    }

    return { totalRegistros: datos.length };
}

function calcularDiasMora(fechaFactura) {
    if (!fechaFactura) return 0;
    const dias = Math.floor((new Date() - new Date(fechaFactura)) / (1000 * 60 * 60 * 24));
    return Math.max(0, dias - 30);
}

// ============================================================
// EXPORTADOR A CSV (Excel-compatible)
// ============================================================
function exportarCSV(res, datos, nombreArchivo) {
    if (datos.length === 0) {
        return res.status(400).json({ error: 'No hay datos para exportar' });
    }

    const headers = Object.keys(datos[0]);
    const csv = [
        headers.join(';'),
        ...datos.map(row => headers.map(h => {
            const val = row[h];
            if (val === null || val === undefined) return '';
            if (typeof val === 'number') return val.toString().replace('.', ',');
            if (typeof val === 'object') return JSON.stringify(val);
            return `"${String(val).replace(/"/g, '""')}"`;
        }).join(';'))
    ].join('\n');

    const bom = '\uFEFF';
    const buffer = Buffer.from(bom + csv, 'utf-8');

    res.setHeader('Content-Type', 'text/csv; charset=utf-8');
    res.setHeader('Content-Disposition', `attachment; filename="${nombreArchivo}.csv"`);
    res.send(buffer);
}

// ============================================================
// EXPORTADOR A PDF (basico con jsPDF)
// ============================================================
function exportarPDF(res, datos, resumen, nombreArchivo) {
    if (datos.length === 0) {
        return res.status(400).json({ error: 'No hay datos para exportar' });
    }

    if (!res.app.locals.jspdf) {
        return res.status(500).json({
            error: 'Exportacion PDF no disponible',
            sugerencia: 'Use formato "excel" o "json"'
        });
    }

    // Fallback: devolver JSON con indicador de que PDF requiere configuracion adicional
    res.json({
        exito: true,
        nota: 'Exportacion PDF requiere jsPDF configurado en el servidor. Use formato "excel" para descarga inmediata.',
        resumen,
        datos
    });
}

7. Riesgos y Mitigaciones

7.1 Riesgos de implementación

RIESGO ALTO: Colisión de rutas
Si se usa /api/reportes sin versión, Express podría interceptar /api/reportes/caracas antes de que llegue a routes/tiendas.js.
Mitigación: Usar /api/reportes/v1 como prefijo. Las rutas legacy de tiendas siguen funcionando en /api/tiendas/:tienda y /api/reportes/:tienda.
RIESGO ALTO: Servidor no reiniciado
Si se sube el archivo pero no se reinicia el servicio de Windows, Node.js sigue ejecutando la versión anterior en memoria.
Mitigación: Reiniciar el servicio obligatoriamente después de subir reportes.js y modificar server.js. Verificar en los logs que aparezca API de reportes disponible en /api/reportes/v1/generar.
RIESGO MEDIO: Consultas pesadas
Un reporte sin filtros sobre una tabla con miles de registros puede demorar varios segundos y consumir memoria.
Mitigación: La query tiene LIMIT 1000 por defecto. En futuras versiones, agregar índices en fecha_factura, deuda y nombre_apellido.
RIESGO MEDIO: Permisos incorrectos
Si la validación de req.usuario.tienda falla, un operador podría ver datos de otra tienda.
Mitigación: La API incluye validación explícita: if (req.usuario.rol === 'operador' && req.usuario.tienda !== tienda) return 403. Probar con usuario operador de cada tienda.
RIESGO BAJO: Dependencia de formato
Si se solicita formato PDF pero jsPDF no está instalado en el servidor, la exportación falla.
Mitigación: El endpoint detecta la ausencia de jsPDF y devuelve JSON con mensaje explicativo, sugiriendo usar formato "excel".

7.2 Riesgos de seguridad

RiesgoProbabilidadImpactoMitigación implementada

async function generarReporte() {
  const token = localStorage.getItem('token');

  const body = {
    tienda: 'caracas',
    tipo: 'cartera',
    formato: 'json',
    filtros: {
      estado: 'deudor',
      fechaDesde: '2026-07-01',
      fechaHasta: '2026-07-31'
    },
    ordenarPor: 'deuda',
    orden: 'desc'
  };

  const response = await fetch('/api/reportes/v1/generar', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer ' + token
    },
    body: JSON.stringify(body)
  });

  const data = await response.json();

  if (data.exito) {
    console.log('Resumen:', data.resumen);
    console.log('Datos:', data.datos);
    // data.resumen = { totalRegistros, totalFacturado, totalDepositado, totalDeuda, porcentajeRecuperacion }
  } else {
    console.error('Error:', data.error);
  }
}
