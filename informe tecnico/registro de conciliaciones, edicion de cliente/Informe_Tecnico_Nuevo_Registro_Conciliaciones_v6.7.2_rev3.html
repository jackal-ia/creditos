1. Resumen Ejecutivo

1.1 Propósito del rediseño

El módulo de Conciliaciones Bancarias actual permite registrar una factura y su primera cuota de pago de forma aislada. El negocio requiere que al crear un nuevo crédito se capture la estructura financiera completa desde el origen: monto facturado en Bs y en $, depósito inicial (down payment), número de cuotas, deuda resultante y monto de cada cuota mensual en dólares.

2.2 Semántica de cuota_1 a cuota_11

Cada cuota tiene 5 campos asociados, repitiendo el patrón para las 11 cuotas:

cuota_N              → numeric(15,2)  → Monto en Bs depositado por el cliente
ref_cuota_N          → varchar(50)    → Número de referencia bancaria
fecha_cuota_N        → date           → Fecha del depósito
tasa_cuota_N         → numeric(15,4)  → Tasa BCV del día del depósito
dolar_depositado_cuota_N → numeric(15,2) → Equivalente en $ (cuota_N / tasa)
Observación crítica: En el diseño actual, cuota_1 representa el primer pago mensual del cliente, no el depósito inicial. Esto genera confusión operativa porque el "down payment" (inicial) no tiene campo propio. Los registros existentes almacenan la inicial en cuota_1 y los pagos subsiguientes en cuota_2..11, lo cual es semánticamente incorrecto pero funcional.

Decisión arquitectónica: Para no romper los registros existentes, se crean campos nuevos (inicial_bs, inicial_usd, etc.) exclusivamente para nuevos registros. Los campos cuota_1..11 siguen siendo pagos mensuales. En un futuro (v6.9+) se puede migrar la semántica, pero eso requiere script de transformación de datos con backup completo.

4.3 Manejo de redondeo (corregido)

La versión anterior usaba Math.round(valor * 100) / 100, que es vulnerable a errores de precisión del estándar IEEE 754. La versión corregida usa Number.EPSILON para compensar:

// Función de redondeo unificada (frontend y backend)
function redondearDecimales(valor, decimales = 2) {
    if (typeof valor !== 'number' || isNaN(valor) || !isFinite(valor)) return 0;
    const factor = Math.pow(10, decimales);
    // Number.EPSILON corrige errores de precisión de punto flotante
    return Math.round((valor + Number.EPSILON) * factor) / factor;
}

function aDosDecimales(valor) {
    return redondearDecimales(valor, 2).toFixed(2);
}

// Ejemplo corregido:
// redondearDecimales(123456.55 / 742.8108) = redondearDecimales(166.1987...) = 166.20
// Sin EPSILON podría dar 166.19 en algunos casos límite
¿Por qué Number.EPSILON? En JavaScript, 0.1 + 0.2 !== 0.3 debido a la representación binaria de decimales. Al multiplicar por el factor de redondeo, pequeños errores de precisión pueden hacer que Math.round redondee hacia abajo en lugar de arriba. Number.EPSILON (≈ 2.22×10⁻¹⁶) compensa ese error sin afectar el resultado para números normales.

4.4 Descalce de centavos y última cuota

Problema identificado: Si deuda_usd = 100.00 y total_cuotas = 3, entonces 100 / 3 = 33.3333.... Redondeando a 2 decimales: 3 cuotas de 33.33 = 99.99. Queda 1 centavo sin saldar.

Solución: Las primeras N-1 cuotas usan el redondeo estándar. La última cuota absorbe el remanente:

function calcularPlanCuotas(deudaUSD, totalCuotas) {
    const cuotaBase = redondearDecimales(deudaUSD / totalCuotas, 2);
    const acumulado = redondearDecimales(cuotaBase * (totalCuotas - 1), 2);
    const ultimaCuota = redondearDecimales(deudaUSD - acumulado, 2);

    return {
        monto_cuota_regular: cuotaBase,      // cuotas 1 a N-1
        monto_ultima_cuota: ultimaCuota     // cuota N (absorbe centavos)
    };
}

// Ejemplo: deuda = 100.00, cuotas = 3
// cuotaBase = 33.33
// acumulado = 33.33 * 2 = 66.66
// ultimaCuota = 100.00 - 66.66 = 33.34
// Total: 33.33 + 33.33 + 33.34 = 100.00 ✅
Nota: El campo monto_cuota_usd en la base de datos almacena la cuota base (redondeada). El frontend y los reportes deben aplicar la lógica del remanente al mostrar la última cuota. Para simplificar, en esta versión almacenamos solo la cuota base y el sistema de conciliaciones maneja el ajuste visualmente.

6. API REST — Cambios en Backend

6.1 Sanitización de parámetro tienda (aplicar a TODAS las rutas)

Error identificado: El código anterior concatenaba tienda_${tienda} directamente en la consulta SQL, lo cual es vulnerable a inyección si el parámetro no está sanitizado.

Solución: Middleware de whitelist que valida el parámetro antes de usarlo. Debe aplicarse a TODAS las rutas que usen :tienda, no solo al POST:

// middleware/validarTienda.js
const TIENDAS_PERMITIDAS = ['caracas', 'maracay', 'maracaibo'];

function validarTienda(req, res, next) {
    const tienda = req.params.tienda ? req.params.tienda.toLowerCase().trim() : '';
    if (!TIENDAS_PERMITIDAS.includes(tienda)) {
        return res.status(400).json({ error: 'Tienda no válida' });
    }
    req.params.tienda = tienda; // Sanitizado
    next();
}

module.exports = { validarTienda };

// ============================
// routes/tiendas.js — APLICAR A TODAS LAS RUTAS
// ============================
const { validarTienda } = require('../middleware/validarTienda');

// GET listar clientes
router.get('/:tienda', verificarToken, validarTienda, async (req, res) => { ... });

// POST crear cliente
router.post('/:tienda', verificarToken, soloAdmin, validarTienda, async (req, res) => { ... });

// GET ver cliente
router.get('/:tienda/:id', verificarToken, validarTienda, async (req, res) => { ... });

// PUT editar cliente
router.put('/:tienda/:id', verificarToken, soloAdmin, validarTienda, async (req, res) => { ... });

// DELETE eliminar cliente
router.delete('/:tienda/:id', verificarToken, soloAdmin, validarTienda, async (req, res) => { ... });

6.2 Rate limiting en endpoint BCV (anti-DoS)

Error identificado: El endpoint /api/bcv/tasa sin rate limiting podría ser explotado para hacer múltiples peticiones a la API externa del BCV, causando bloqueo o consumo excesivo de recursos.

Solución: Agregar rate limiting específico para el endpoint BCV:

// routes/bcv.js — rate limiting
const rateLimit = require('express-rate-limit');

const bcvLimiter = rateLimit({
    windowMs: 60 * 1000, // 1 minuto
    max: 30,              // 30 peticiones por minuto por IP
    message: { 
        error: 'Demasiadas peticiones de tasa BCV. Intente nuevamente en un minuto.' 
    },

6.5 Cálculos en el servidor

El backend debe usar la misma función de redondeo que el frontend para evitar discrepancias:

// routes/tiendas.js — funciones de utilidad
function redondearDecimales(valor, decimales = 2) {
    if (typeof valor !== 'number' || isNaN(valor) || !isFinite(valor)) return 0;
    const factor = Math.pow(10, decimales);
    return Math.round((valor + Number.EPSILON) * factor) / factor;
}

function validarCalculos(body) {
    const tolerancia = 0.01;

    // 1. Validar monto_facturado_divisa
    const calculadoMontoUSD = redondearDecimales(
        parseFloat(body.monto_factura) / parseFloat(body.tasa_bcv_factura)
    );
    if (Math.abs(calculadoMontoUSD - parseFloat(body.monto_facturado_divisa)) > tolerancia) {
        throw new Error('Monto Facturado $ no coincide con el cálculo');
    }

    // 2. Validar inicial_usd
    const calculadoInicialUSD = redondearDecimales(
        parseFloat(body.inicial_bs) / parseFloat(body.tasa_inicial)
    );
    if (Math.abs(calculadoInicialUSD - parseFloat(body.inicial_usd)) > tolerancia) {
        throw new Error('Inicial $ no coincide con el cálculo');
    }

    // 3. Validar monto_cuota_usd
    const deudaUSD = redondearDecimales(
        parseFloat(body.monto_facturado_divisa) - parseFloat(body.inicial_usd)
    );
    const cuotaUSD = redondearDecimales(deudaUSD / parseInt(body.cuotas));
    if (Math.abs(cuotaUSD - parseFloat(body.monto_cuota_usd)) > tolerancia) {
        throw new Error('Monto de cuota no coincide con el cálculo');
    }

    // 4. Validar que inicial no supere el monto
    if (parseFloat(body.inicial_bs) > parseFloat(body.monto_factura)) {
        throw new Error('Inicial no puede ser mayor al monto total');
    }

    // 5. Validar fechas lógicas
    if (new Date(body.fecha_inicial) < new Date(body.fecha_factura)) {
        throw new Error('Fecha de inicial no puede ser anterior a la fecha de la factura');
    }

    // 6. Validar rango de tasas
    const tasaFactura = parseFloat(body.tasa_bcv_factura);
    const tasaInicial = parseFloat(body.tasa_inicial);
    if (tasaFactura <= 0.1 || tasaFactura > 10000 || tasaInicial <= 0.1 || tasaInicial > 10000) {
        throw new Error('Tasa BCV fuera de rango válido');
    }

    // 7. Validar que cuotas sea entero
    const cuotas = parseInt(body.cuotas);
    if (isNaN(cuotas) || cuotas < 1 || cuotas > 11) {
        throw new Error('Cuotas debe ser un número entero entre 1 y 11');
    }

    return true;
}
Principio de defensa en profundidad: El frontend calcula para UX (feedback inmediato). El backend recalcula para seguridad (evita que un usuario malicioso envíe valores falsos manipulando la petición HTTP). Ambos usan la misma función de redondeo con Number.EPSILON para garantizar consistencia.

7.2 Eventos con debounce y AbortController

Problema identificado: El código anterior usaba addEventListener('input', ...) sin debounce, generando múltiples peticiones a la API BCV por cada tecla presionada.

Solución:

  • Debounce de 300ms: Solo se ejecuta el cálculo 300ms después de que el usuario deja de escribir.
  • AbortController: Cancela peticiones fetch anteriores si el usuario cambia el campo antes de que termine.
  • Cache en sessionStorage: Evita pedir la misma tasa BCV dos veces en la misma sesión.

let abortControllerBCV = null;

async function obtenerTasaBCV(fecha) {
    if (!fecha) return null;

    const cacheKey = `tasa_bcv_${fecha}`;
    const cached = sessionStorage.getItem(cacheKey);

    if (cached) {
        const tasa = parseFloat(cached);
        if (validarTasaBCV(tasa)) return tasa;
        sessionStorage.removeItem(cacheKey);
    }

    // Cancelar petición anterior si existe
    if (abortControllerBCV) {
        abortControllerBCV.abort();
    }
    abortControllerBCV = new AbortController();

    try {
        const timeoutId = setTimeout(() => abortControllerBCV.abort(), 5000);

        const response = await fetch(`/api/bcv/tasa?fecha=${fecha}`, {
            signal: abortControllerBCV.signal,
            headers: { 'Authorization': 'Bearer ' + localStorage.getItem('token') }

        const data = await response.json();
        if (!validarTasaBCV(data.tasa)) {
            throw new Error('Tasa inválida');
        }

        sessionStorage.setItem(cacheKey, data.tasa);
        return data.tasa;

        if (error.name === 'AbortError') {
            console.warn('Petición BCV cancelada (nueva petición iniciada)');

            console.warn('Error obteniendo tasa BCV:', error.message);

// routes/bcv.js — modificación
const rateLimit = require('express-rate-limit');

const bcvLimiter = rateLimit({
    windowMs: 60 * 1000,
    max: 30,
    message: { error: 'Demasiadas peticiones de tasa BCV' }
});

router.get('/tasa', verificarToken, bcvLimiter, async (req, res) => {
    const fecha = req.query.fecha;

    try {
        const fechaConsulta = fecha || new Date().toISOString().split('T')[0];

        // 1. Intentar obtener tasa exacta para la fecha
        let tasa = await obtenerTasaBCVExacta(fechaConsulta);

        // 2. Si no existe, buscar la tasa más reciente anterior
        if (!tasa) {
            tasa = await obtenerTasaBCVUltimaDisponible(fechaConsulta);
            if (tasa) {
                return res.json({
                    tasa: tasa.valor,
                    fecha: tasa.fecha,
                    fuente: 'bcv.org.ve (última disponible)',
                    nota: 'Tasa del último día hábil anterior'
                });
            }
        }

        if (tasa) {
            res.json({ tasa: tasa.valor, fecha: fechaConsulta, fuente: 'bcv.org.ve' });
        } else {
            res.status(404).json({ 
                error: 'Tasa no disponible',
                fecha: fechaConsulta 
            });
        }
    } catch (err) {
        res.status(500).json({ error: 'Error consultando tasa BCV' });
    }
});

// SQL para buscar tasa del último día hábil anterior
async function obtenerTasaBCVUltimaDisponible(fecha) {
    const query = `
        SELECT tasa, fecha 
        FROM bcv_tasas 
        WHERE fecha <= $1 
        ORDER BY fecha DESC 
        LIMIT 1
    `;
    const result = await pool.query(query, [fecha]);
    return result.rows[0] || null;
}

Fallback manual

Si la API del BCV no tiene datos para la fecha solicitada y no hay registro histórico, el frontend debe:

  1. Mostrar un mensaje: "No se pudo obtener la tasa automáticamente. Por favor ingrésela manualmente."
  2. Habilitar el campo de tasa para edición manual (readOnly = false).
  3. El operador puede consultar la tasa en bcv.org.ve y escribirla.
  4. La validación de rango (0.1 - 10000) asegura que el valor manual sea razonable.
Nota: Si no se implementa el endpoint con fecha en esta versión, el frontend puede usar la tasa del día actual como aproximación, con la opción de que el operador la corrija manualmente. Esto es aceptable si las facturas se registran el mismo día de su emisión.

Implicaciones

  • Registros viejos: La "inicial" está en cuota_1. Los pagos mensuales empiezan en cuota_2.
  • Registros nuevos: La "inicial" está en inicial_bs/usd. Los pagos mensuales empiezan en cuota_1.
  • Para el operador: No hay cambio visible. El sistema internamente sabe qué campos usar según si el registro tiene inicial_bs o no.

9.3 COALESCE para consultas unificadas

Los reportes y estadísticas que necesiten mostrar la "inicial" de todos los registros (viejos y nuevos) deben usar COALESCE:

-- Ejemplo: consulta unificada que funciona para registros viejos y nuevos
SELECT 
    id,
    nro_factura,
    nombre_apellido,
    COALESCE(inicial_bs, cuota_1) AS inicial_bs_unificada,
    COALESCE(inicial_usd, dolar_depositado_cuota_1) AS inicial_usd_unificada,
    COALESCE(ref_inicial, ref_cuota_1) AS ref_inicial_unificada,
    COALESCE(fecha_inicial, fecha_cuota_1) AS fecha_inicial_unificada,
    monto_factura,
    monto_facturado_divisa,
    cuotas,
    deuda
FROM tienda_caracas;
Advertencia para futuras versiones: Si en v6.9+ se decide unificar la semántica (migrar registros viejos a los nuevos campos), se necesitará un script de transformación de datos que:
  1. Copie cuota_1 → inicial_bs
  2. Copie ref_cuota_1 → ref_inicial
  3. Copie fecha_cuota_1 → fecha_inicial
  4. Copie dolar_depositado_cuota_1 → inicial_usd
  5. Recalcule tasa_inicial = inicial_bs / inicial_usd
  6. Mueva cuota_2 → cuota_1, cuota_3 → cuota_2, etc.
Esto es riesgoso y debe hacerse con backup completo de la base de datos.

const DEBOUNCE_MS = 300;
const TASA_MIN = 0.1;
const TASA_MAX = 10000;

// Redondeo unificado con backend
function redondearDecimales(valor, decimales = 2) {
    if (typeof valor !== 'number' || isNaN(valor) || !isFinite(valor)) return 0;
    const factor = Math.pow(10, decimales);
    return Math.round((valor + Number.EPSILON) * factor) / factor;
}

function aDosDecimales(valor) {
    return redondearDecimales(valor, 2).toFixed(2);
}

// Validaciones
function validarTasaBCV(tasa) {
    if (!tasa || typeof tasa !== 'number') return false;
    if (tasa <= TASA_MIN || tasa > TASA_MAX) return false;
    return true;
}

function validarValorMonetario(valor) {
    if (typeof valor !== 'number' || isNaN(valor)) return false;
    if (valor < 0) return false;
    return true;
}

// Tasa BCV con cache y AbortController
let abortControllerBCV = null;

async function obtenerTasaBCV(fecha) {
    if (!fecha) return null;

    const cacheKey = `tasa_bcv_${fecha}`;
    const cached = sessionStorage.getItem(cacheKey);
    if (cached) {
        const tasa = parseFloat(cached);
        if (validarTasaBCV(tasa)) return tasa;
        sessionStorage.removeItem(cacheKey);
    }

    if (abortControllerBCV) abortControllerBCV.abort();
    abortControllerBCV = new AbortController();

    try {
        const timeoutId = setTimeout(() => abortControllerBCV.abort(), 5000);
        const response = await fetch(`/api/bcv/tasa?fecha=${fecha}`, {
            signal: abortControllerBCV.signal,
            headers: { 'Authorization': 'Bearer ' + localStorage.getItem('token') }
        });
        clearTimeout(timeoutId);

        if (!response.ok) throw new Error('Error en la API');
        const data = await response.json();
        if (!validarTasaBCV(data.tasa)) throw new Error('Tasa inválida');

        sessionStorage.setItem(cacheKey, data.tasa);
        return data.tasa;
    } catch (error) {
        if (error.name !== 'AbortError') {
            console.warn('Error obteniendo tasa BCV:', error.message);
        }
        return null;
    }
}

async function calcularMontoFacturadoUSD() {
    clearTimeout(tMontoUSD);
    tMontoUSD = setTimeout(async () => {
        const montoBs = parseFloat(document.getElementById('nueva-monto').value) || 0;
        const fechaFactura = document.getElementById('nueva-fecha-factura').value;

        if (!validarValorMonetario(montoBs) || montoBs <= 0 || !fechaFactura) {
            document.getElementById('nueva-monto-usd').value = '';
            return;
        }

        let tasa = parseFloat(document.getElementById('nueva-tasa-factura').value);
        if (!validarTasaBCV(tasa)) {
            tasa = await obtenerTasaBCV(fechaFactura);
            if (tasa) document.getElementById('nueva-tasa-factura').value = tasa.toFixed(4);
        }

        if (validarTasaBCV(tasa)) {
            const usd = redondearDecimales(montoBs / tasa);
            document.getElementById('nueva-monto-usd').value = aDosDecimales(usd);
            calcularDeudaYCuota();
        }
    }, DEBOUNCE_MS);
