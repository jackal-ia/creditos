1. Resumen Ejecutivo

1.1 Propósito del rediseño

El módulo de Conciliaciones Bancarias actual permite registrar una factura y su primera cuota de pago de forma aislada. El negocio requiere que al crear un nuevo crédito se capture la estructura financiera completa desde el origen: monto facturado en Bs y en $, depósito inicial (down payment), número de cuotas, deuda resultante y monto de cada cuota mensual en dólares.

2.2 Semántica de cuota_1 a cuota_11

Cada cuota tiene 5 campos asociados, repitiendo el patrón para las 11 cuotas:

cuota_N              → numeric(15,2)  → Monto en Bs depositado por el cliente
ref_cuota_N          → varchar(50)    → Número de referencia bancaria
fecha_cuota_N        → date           → Fecha del depósito
tasa_cuota_N         → numeric(15,4)  → Tasa BCV del día del depósito
dolar_depositado_cuota_N → numeric(15,2) → Equivalente en $ (cuota_N / tasa)
Observación crítica: En el diseño actual, cuota_1 representa el primer pago mensual del cliente, no el depósito inicial. Esto genera confusión operativa porque el "down payment" (inicial) no tiene campo propio. Los registros existentes almacenan la inicial en cuota_1 y los pagos subsiguientes en cuota_2..11, lo cual es semánticamente incorrecto pero funcional.

Decisión arquitectónica: Para no romper los registros existentes, se crean campos nuevos (inicial_bs, inicial_usd, etc.) exclusivamente para nuevos registros. Los campos cuota_1..11 siguen siendo pagos mensuales. En un futuro (v6.9+) se puede migrar la semántica, pero eso requiere script de transformación de datos con backup completo.

4.3 Manejo de redondeo (corregido)

La versión anterior usaba Math.round(valor * 100) / 100, vulnerable a errores de precisión del estándar IEEE 754. La versión corregida usa Number.EPSILON:

function redondearDecimales(valor, decimales = 2) {
    if (typeof valor !== 'number' || isNaN(valor) || !isFinite(valor)) return 0;
    const factor = Math.pow(10, decimales);
    return Math.round((valor + Number.EPSILON) * factor) / factor;
}
function aDosDecimales(valor) {
    return redondearDecimales(valor, 2).toFixed(2);
}
¿Por qué Number.EPSILON? En JavaScript, 0.1 + 0.2 !== 0.3 debido a la representación binaria de decimales. Number.EPSILON (≈ 2.22×10⁻¹⁶) compensa ese error sin afectar el resultado para números normales.

4.4 Descalce de centavos y última cuota

Problema: Si deuda_usd = 100.00 y total_cuotas = 3, entonces 100 / 3 = 33.3333.... Redondeando: 3 cuotas de 33.33 = 99.99. Queda 1 centavo sin saldar.

Solución: Las primeras N-1 cuotas usan el redondeo estándar. La última cuota absorbe el remanente:

function calcularPlanCuotas(deudaUSD, totalCuotas) {
    const cuotaBase = redondearDecimales(deudaUSD / totalCuotas, 2);
    const acumulado = redondearDecimales(cuotaBase * (totalCuotas - 1), 2);
    const ultimaCuota = redondearDecimales(deudaUSD - acumulado, 2);
    return { monto_cuota_regular: cuotaBase, monto_ultima_cuota: ultimaCuota };
}
// Ejemplo: deuda = 100.00, cuotas = 3
// cuotaBase = 33.33, acumulado = 66.66, ultimaCuota = 33.34
// Total: 33.33 + 33.33 + 33.34 = 100.00 ✅
Nota: El campo monto_cuota_usd en la base de datos almacena la cuota base (redondeada). El frontend y los reportes deben aplicar la lógica del remanente al mostrar la última cuota.

function redondearDecimales(valor, decimales = 2) {
    if (typeof valor !== 'number' || isNaN(valor) || !isFinite(valor)) return 0;
    const factor = Math.pow(10, decimales);
    return Math.round((valor + Number.EPSILON) * factor) / factor;
}

function validarCalculos(body) {
    const tolerancia = 0.01;
    const calculadoMontoUSD = redondearDecimales(parseFloat(body.monto_factura) / parseFloat(body.tasa_bcv_factura));
    if (Math.abs(calculadoMontoUSD - parseFloat(body.monto_facturado_divisa)) > tolerancia) {
        throw new Error('Monto Facturado $ no coincide con el cálculo');
    }
    const calculadoInicialUSD = redondearDecimales(parseFloat(body.inicial_bs) / parseFloat(body.tasa_inicial));
    if (Math.abs(calculadoInicialUSD - parseFloat(body.inicial_usd)) > tolerancia) {
        throw new Error('Inicial $ no coincide con el cálculo');
    }
    const deudaUSD = redondearDecimales(parseFloat(body.monto_facturado_divisa) - parseFloat(body.inicial_usd));
    const cuotaUSD = redondearDecimales(deudaUSD / parseInt(body.cuotas));
    if (Math.abs(cuotaUSD - parseFloat(body.monto_cuota_usd)) > tolerancia) {
        throw new Error('Monto de cuota no coincide con el cálculo');
    }
    if (parseFloat(body.inicial_bs) > parseFloat(body.monto_factura)) {
        throw new Error('Inicial no puede ser mayor al monto total');
    }
    if (new Date(body.fecha_inicial) < new Date(body.fecha_factura)) {
        throw new Error('Fecha de inicial no puede ser anterior a la fecha de la factura');
    }
    const tasaFactura = parseFloat(body.tasa_bcv_factura);
    const tasaInicial = parseFloat(body.tasa_inicial);
    if (tasaFactura <= 0.0001 || tasaFactura > 10000 || tasaInicial <= 0.0001 || tasaInicial > 10000) {
        throw new Error('Tasa BCV fuera de rango válido');
    }
    const cuotas = parseInt(body.cuotas);
    if (isNaN(cuotas) || cuotas < 1 || cuotas > 11) {
        throw new Error('Cuotas debe ser un número entero entre 1 y 11');
    }
    return true;
}
Principio de defensa en profundidad: El frontend calcula para UX (feedback inmediato). El backend recalcula para seguridad. Ambos usan la misma función de redondeo con Number.EPSILON.

  • Debounce de 300ms: Solo se ejecuta el cálculo 300ms después de que el usuario deja de escribir.
  • AbortController: Cancela peticiones fetch anteriores si el usuario cambia el campo antes de que termine.

let abortControllerBCV = null;
async function obtenerTasaBCV(fecha) {
    if (!fecha) return null;
    const cacheKey = `tasa_bcv_${fecha}`;
    const cached = sessionStorage.getItem(cacheKey);
    if (cached) {
        const tasa = parseFloat(cached);
        if (validarTasaBCV(tasa)) return tasa;
        sessionStorage.removeItem(cacheKey);
    }
    if (abortControllerBCV) abortControllerBCV.abort();
    abortControllerBCV = new AbortController();
    try {
        const timeoutId = setTimeout(() => abortControllerBCV.abort(), 5000);
        const response = await fetch(`/api/bcv/tasa?fecha=${fecha}`, {
            signal: abortControllerBCV.signal,
            headers: { 'Authorization': 'Bearer ' + localStorage.getItem('token') }
        });
        clearTimeout(timeoutId);
        if (!response.ok) throw new Error('Error en la API');
        const data = await response.json();
        if (!validarTasaBCV(data.tasa)) throw new Error('Tasa inválida');
        sessionStorage.setItem(cacheKey, data.tasa);
        return data.tasa;

function calcularResumenMontos(cliente) {

    // (ya existe para todos los registros, viejo y nuevo)

        || parseFloat(cliente.monto_factura) / parseFloat(cliente.tasa_bcv_factura || 1);

    const deudaBs = parseFloat(cliente.monto_factura) - inicialBs;

    const totalCuotas = parseInt(cliente.cuotas) || 4;
    const montoCuotaUSD = esNuevo ? parseFloat(cliente.monto_cuota_usd) : redondearDecimales(deudaUSD / totalCuotas);

    let totalDepositadoBs = inicialBs;
    let totalDepositadoUSD = inicialUSD;
    let cuotasPagadas = 0;

    for (let i = 1; i <= 11; i++) {
        const cuotaBs = parseFloat(cliente[`cuota_${i}`] || 0);
        const cuotaUSD = parseFloat(cliente[`dolar_depositado_cuota_${i}`] || 0);
        if (cuotaBs > 0) {
            totalDepositadoBs += cuotaBs;
            totalDepositadoUSD += cuotaUSD;
            cuotasPagadas++;
        }
    }

    const deudaPendienteBs = parseFloat(cliente.monto_factura) - totalDepositadoBs;
    const deudaPendienteUSD = montoFacturadoUSD - totalDepositadoUSD;
    const proximaCuota = Math.min(montoCuotaUSD, deudaPendienteUSD);

    return {
        montoFacturadoUSD, inicialBs, inicialUSD, deudaUSD, deudaBs,
        totalCuotas, montoCuotaUSD, totalDepositadoBs, totalDepositadoUSD,
        deudaPendienteBs, deudaPendienteUSD, cuotasPagadas, proximaCuota
    };
}

Detección de Discrepancias en Cuotas — NUEVO v6.7.2-rev9

Problema de negocio: Un cliente puede pagar una cuota con un monto menor al esperado (ej. debe $47.13 pero paga $40.00). El sistema debe detectar esto, mostrar una alerta visual en rojo, y guardar el registro para auditoría.

Lógica de detección

function calcularDiscrepanciaCuota(numCuota, totalCuotas, montoCuotaUSD, deudaPendienteUSD, dolarRecibido) {
    const recibido = parseFloat(dolarRecibido) || 0;
    if (recibido <= 0) return null; // Cuota no pagada, sin discrepancia

    // La última cuota pagada puede ser el remanente (deuda pendiente), no la cuota base
    const cuotasPagadas = contarCuotasPagadas(); // contar cuotas 1..N con valor > 0
    const esUltimaCuotaPagada = cuotasPagadas === numCuota;

    // Esperado: cuota base para cuotas regulares, deuda restante para la última
    const esperado = esUltimaCuotaPagada && numCuota === totalCuotas
        ? deudaPendienteUSD + recibido  // deuda antes de esta cuota
        : montoCuotaUSD;

    const diferencia = redondearDecimales(esperado - recibido);

    if (diferencia > 0.01) {
        return {
            esperado: redondearDecimales(esperado),
            recibido: recibido,
            diferencia: diferencia,
            alerta: true
        };
    }
    return null; // Sin discrepancia (recibido >= esperado)
}

function calcularResumenMontos(cliente) {
    const esNuevo = esRegistroNuevoV672(cliente);

    // CORRECCIÓN v6.7.2-rev9: Usar monto_facturado_divisa directamente
    const montoFacturadoUSD = parseFloat(cliente.monto_facturado_divisa) 
        || parseFloat(cliente.monto_factura) / parseFloat(cliente.tasa_bcv_factura || 1);

    const inicialBs = esNuevo ? parseFloat(cliente.inicial_bs) : parseFloat(cliente.cuota_1 || 0);
    const inicialUSD = esNuevo ? parseFloat(cliente.inicial_usd) : parseFloat(cliente.dolar_depositado_cuota_1 || 0);

    const deudaUSD = montoFacturadoUSD - inicialUSD;
    const deudaBs = parseFloat(cliente.monto_factura) - inicialBs;

    const totalCuotas = parseInt(cliente.cuotas) || 4;
    const montoCuotaUSD = esNuevo ? parseFloat(cliente.monto_cuota_usd) : redondearDecimales(deudaUSD / totalCuotas);

    let totalDepositadoBs = inicialBs;
    let totalDepositadoUSD = inicialUSD;
    let cuotasPagadas = 0;

    for (let i = 1; i <= 11; i++) {
        const cuotaBs = parseFloat(cliente[`cuota_${i}`] || 0);
        const cuotaUSD = parseFloat(cliente[`dolar_depositado_cuota_${i}`] || 0);
        if (cuotaBs > 0) {
            totalDepositadoBs += cuotaBs;
            totalDepositadoUSD += cuotaUSD;
            cuotasPagadas++;
        }
    }

    const deudaPendienteBs = parseFloat(cliente.monto_factura) - totalDepositadoBs;
    const deudaPendienteUSD = montoFacturadoUSD - totalDepositadoUSD;
    const proximaCuota = Math.min(montoCuotaUSD, deudaPendienteUSD);

    return {
        montoFacturadoUSD, inicialBs, inicialUSD, deudaUSD, deudaBs,
        totalCuotas, montoCuotaUSD, totalDepositadoBs, totalDepositadoUSD,
        deudaPendienteBs, deudaPendienteUSD, cuotasPagadas, proximaCuota
    };
}

Problema

El sistema actual obtiene la tasa BCV del día actual mediante /api/bcv/tasa. El nuevo formulario necesita la tasa de fechas pasadas (fecha de la factura y fecha del depósito inicial).

Solución propuesta: Endpoint con parámetro de fecha + fallback

GET /api/bcv/tasa?fecha=2026-07-28

{ "tasa": 742.8108, "fecha": "2026-07-28", "fuente": "bcv.org.ve" }

// Respuesta si no hay tasa para esa fecha:

Implementación backend con fallback

const rateLimit = require('express-rate-limit');
const bcvLimiter = rateLimit({
    windowMs: 60 * 1000, max: 30,
    message: { error: 'Demasiadas peticiones de tasa BCV' }
});
router.get('/tasa', verificarToken, bcvLimiter, async (req, res) => {
    const fecha = req.query.fecha;
    try {
        const fechaConsulta = fecha || new Date().toISOString().split('T')[0];
        let tasa = await obtenerTasaBCVExacta(fechaConsulta);
        if (!tasa) {
            tasa = await obtenerTasaBCVUltimaDisponible(fechaConsulta);
            if (tasa) {
                return res.json({
                    tasa: tasa.valor, fecha: tasa.fecha,
                    fuente: 'bcv.org.ve (última disponible)',
                    nota: 'Tasa del último día hábil anterior'
                });
            }
        }
        if (tasa) {
            res.json({ tasa: tasa.valor, fecha: fechaConsulta, fuente: 'bcv.org.ve' });
        } else {
            res.status(404).json({ error: 'Tasa no disponible', fecha: fechaConsulta });
        }
    } catch (err) {
        res.status(500).json({ error: 'Error consultando tasa BCV' });
    }
});

async function obtenerTasaBCVUltimaDisponible(fecha) {
    const query = `SELECT tasa, fecha FROM bcv_tasas WHERE fecha <= $1 ORDER BY fecha DESC LIMIT 1`;
    const result = await pool.query(query, [fecha]);
    return result.rows[0] || null;
}

Fallback manual

Si la API del BCV no tiene datos para la fecha solicitada y no hay registro histórico, el frontend debe:

  1. Mostrar un mensaje: "No se pudo obtener la tasa automáticamente. Por favor ingrésela manualmente."
  2. Habilitar el campo de tasa para edición manual (readOnly = false).
  3. El operador puede consultar la tasa en bcv.org.ve y escribirla.
  4. La validación de rango (0.0001 - 10000) asegura que el valor manual sea razonable.
Nota: Si no se implementa el endpoint con fecha en esta versión, el frontend puede usar la tasa del día actual como aproximación, con la opción de que el operador la corrija manualmente.

10.4 Política de migración manual de registros viejos

Decisión arquitectónica aprobada: La migración de registros viejos al nuevo esquema se realizará manualmente, registro por registro, bajo supervisión del administrador. No se implementa migración automática en esta versión.

Procedimiento de migración manual

  1. Buscar el registro viejo en "Buscar Clientes".
  2. Abrir el modal de edición (clic en editar).
  3. Identificar que es registro viejo (campos nuevos aparecen vacíos).
  4. Copiar los datos de cuota_1 hacia los nuevos campos:
    • cuota_1 → inicial_bs
    • ref_cuota_1 → ref_inicial
    • fecha_cuota_1 → fecha_inicial
    • dolar_depositado_cuota_1 → inicial_usd
    • tasa_cuota_1 → tasa_inicial
  5. Calcular tasa_bcv_factura = monto_factura / monto_facturado_divisa (si no existe).
  6. Calcular monto_cuota_usd = (monto_facturado_divisa - inicial_usd) / cuotas.
  7. Guardar cambios. El registro ahora se comporta como registro nuevo.

Ventajas de la migración manual

VentajaDescripción
Control totalEl admin revisa cada registro antes de migrar, evitando errores masivos.
Rollback individualSi un registro se corrompe, solo se afecta ese registro, no toda la base.
Validación humanaEl admin puede detectar datos inconsistentes en registros viejos y corregirlos antes de migrar.
Sin downtimeNo es necesario detener el sistema para ejecutar un script masivo.
ProgresivoSe pueden migrar registros en lotes pequeños, validando cada lote.

Desventajas y mitigaciones

DesventajaMitigación
Lento para muchos registrosPriorizar registros activos (con deuda pendiente). Los registros cancelados pueden quedar en el esquema viejo indefinidamente.
Requiere tiempo del adminEstimar 2-3 minutos por registro. Con 100 registros activos = ~5 horas de trabajo distribuidas en varios días.
Riesgo de inconsistenciaEl backend valida los cálculos al guardar, rechazando migraciones con errores de redondeo.
Nota para futuras versiones (v6.9+): Si el volumen de registros viejos crece y la migración manual se vuelve inviable, se puede desarrollar un script de migración masiva con backup automático, modo dry-run, migración por lotes de 10 registros, log detallado y ejecución en horario de mantenimiento.

                    };
                }
            }
        }

        // CORRECCIÓN v6.7.2-rev9: Limitar JSONB a máximo 10 discrepancias

function redondearDecimales(valor, decimales = 2) {
    if (typeof valor !== 'number' || isNaN(valor) || !isFinite(valor)) return 0;
    const factor = Math.pow(10, decimales);
    return Math.round((valor + Number.EPSILON) * factor) / factor;
}
function aDosDecimales(valor) { return redondearDecimales(valor, 2).toFixed(2); }

function validarTasaBCV(tasa) {
    if (!tasa || typeof tasa !== 'number') return false;
    if (tasa <= TASA_MIN || tasa > TASA_MAX) return false;
    return true;
}
function validarValorMonetario(valor) {
    if (typeof valor !== 'number' || isNaN(valor)) return false;
    if (valor < 0) return false;
    return true;
}

let abortControllerBCV = null;
async function obtenerTasaBCV(fecha) {
    if (!fecha) return null;
    const cacheKey = `tasa_bcv_${fecha}`;
    const cached = sessionStorage.getItem(cacheKey);
    if (cached) {
        const tasa = parseFloat(cached);
        if (validarTasaBCV(tasa)) return tasa;
        sessionStorage.removeItem(cacheKey);
    }
    if (abortControllerBCV) abortControllerBCV.abort();
    abortControllerBCV = new AbortController();
    try {
        const timeoutId = setTimeout(() => abortControllerBCV.abort(), 5000);
        const response = await fetch(`/api/bcv/tasa?fecha=${fecha}`, {
            signal: abortControllerBCV.signal,
            headers: { 'Authorization': 'Bearer ' + localStorage.getItem('token') }
        });

        const data = await response.json();
        if (!validarTasaBCV(data.tasa)) throw new Error('Tasa inválida');
        sessionStorage.setItem(cacheKey, data.tasa);
        return data.tasa;
    } catch (error) {

}

        if (cuotaUSD) totalUSD += parseFloat(cuotaUSD.value) || 0;
    }
    return totalUSD;
}

function actualizarTotalesModal() {
    const modal = document.getElementById('modal-editar-cliente');
    if (!modal) return;
    let totalBs = 0, totalUSD = 0;
    const inputInicialBs = modal.querySelector('[name="inicial_bs"]');
    const inputInicialUSD = modal.querySelector('[name="inicial_usd"]');
    if (inputInicialBs) totalBs += parseFloat(inputInicialBs.value) || 0;
    if (inputInicialUSD) totalUSD += parseFloat(inputInicialUSD.value) || 0;
    for (let i = 1; i <= 11; i++) {
        const cuotaBs = modal.querySelector(`[name="cuota_${i}"]`);
        const cuotaUSD = modal.querySelector(`[name="dolar_cuota_${i}"]`);
        if (cuotaBs) totalBs += parseFloat(cuotaBs.value) || 0;
        if (cuotaUSD) totalUSD += parseFloat(cuotaUSD.value) || 0;
    }
    const totalBsEl = modal.querySelector('.total-bs');
    const totalUsdEl = modal.querySelector('.total-usd');
    if (totalBsEl) totalBsEl.textContent = totalBs.toFixed(2);
    if (totalUsdEl) totalUsdEl.textContent = totalUSD.toFixed(2) + ' $';
    const montoFactura = parseFloat(modal.querySelector('[name="monto_factura"]').value) || 0;
    const deudaBs = montoFactura - totalBs;
    const deudaBsEl = modal.querySelector('.deuda-pendiente-bs');
    if (deudaBsEl) deudaBsEl.textContent = deudaBs.toFixed(2);
}

function formatearFechaInput(fechaStr) {
    if (!fechaStr) return '';
    const fecha = new Date(fechaStr);
    if (isNaN(fecha.getTime())) return '';
    return fecha.toISOString().split('T')[0];
}
